# 北欧神话项目 PRD（产品需求文档）

> 版本：v3.0（2026-10-19）
> 维护原则：本文档是产品定位与功能边界的**唯一权威来源**。每次功能迭代必须先对照本文档，偏离定位的功能不做；本文档随已上线功能同步更新，避免开发漂移。

---

## 1. 产品定位

**交互性北欧神话资料集成与学习小程序**——本质上是一个**知识类休闲小游戏**：

- 核心体验：**边玩边学**，附带收集与解锁图鉴的过程
- 三支柱：权威资料集成（内容底盘）× 学习体系（伴生式，非课程式）× 基础小游戏（驱动引擎）
- 设计哲学：**收集感与解锁惊喜是引擎，知识是伴生奖励**（图鉴式学习，非教材式学习）
- 明确不做：课程式学习路径、导学关卡、错题本/间隔复习、打分体系、多人对战

## 3. 功能架构（已上线基线，v18）

### 3.1 资料集成（内容底盘）
- 诸神 13 位（阿萨 7/华纳 3/巨人血统 3）：司职、圣物、神圣印记、雷达五维、关系网络
- 生灵 9 + 法器 7（图鉴条目，受解锁体系管控）
- 故事长卷 9 篇（创世 → 诸神黄昏主线）
- 卢恩符文 24（老弗萨克，参详进度）
- 九界（世界树三层结构）、神话编年史
- 待补：条目出处字段（"出自《散文埃达》"小字，P2）、诺伦三女神/女武神/巨人族谱（P2）

### 3.2 学习体系（伴生式）
- 符文图鉴点击参详 + 翻牌游戏的含义伴生显示
- 解锁知识卡：条目合成解锁瞬间全屏展示神话卡（金色碑文层）——知识在惊喜时刻被阅读
- 测验（16 题库/轮 8 题）作为知识查漏的轻入口
- 已砍掉（勿回潮）：学习路径页、导学节点、错题本、间隔复习

### 3.3 角色互动系统
- **神祇眷顾**（favor）：四阶段（立于神前 0 → 蒙神注视 30 → 神恩加身 60 → 眷顾之人 100）；按神差异化供品（偏好 ×1.5、数值一律取整）、阶段箴言、跨阈值神谕事件全屏层
- 生物羁绊（bond，本地版）：与眷顾同构的四阶段引擎 + 喜好/禁忌联动
- 成就称号墙：探索 4 + 智识 2 + 信仰 4，分组展示带计数

### 3.4 碎片经济与收集循环（核心引擎）
- **三层解锁**：直接可见 6（标志性条目）/ 碎片合成 9（3-4 片/条，合成出知识卡）/ 条件解锁 3（海拉=眷顾满级、血鹰=洛基供奉 20 次、密米尔头颅=测验正确率 ≥75%，列表显示 ？？？剪影+条件提示）
- **碎片产出口**（统一聚合掉落 + 「拾得 xx 碎片 ×n」toast）：
  - 测验：答对 1 片/题，通关 +2；每日首战局双倍（2 片/题、通关 +4，答题页金色徽标）
  - 供奉：普通 30% / 偏好供品 50% 概率掉 1 片
  - 每日首访 +1；符文翻牌胜利结算分档 3/2/1 片 + 每日首胜 +1
- **完成度可视化**：档案页总收录大环 + 生灵/法器分环，列表页分区「已收录 n/总数」

### 3.5 每日轻钩子（留存层）
- 每日签到卡（档案页）：三档随机——50% 碎片×2 / 30% 点亮随机未参详符文 / 20% 随机神眷顾+5；连续签到计数、断签重置、边界自动降级兜底
- 每日限次：翻牌每日前 3 局产出碎片（牌运胶囊），跨天重置

### 3.6 小游戏
- 知识测验（16 题库随机 8 题、称号结算）
- 符文记忆翻牌（/memory-game）：24 符文抽 8 对 4×4、3D 翻牌、含义伴生显示、最佳纪录
- 卢恩占卜（箴言体三符文）、神格匹配（本地版）

### 3.7 用户体系
- 本地多档案 + 访客模式：登录页（ᛟ 碑文风、进入/新建双模式、档案 chips、封存二次确认）、密码加盐哈希、LoginGate 门禁
- **档案快照隔离**：progress/bond/favor/game（及碎片/签到/翻牌纪录）随档案换入换出；settings 全局共享

### 3.8 氛围与设置
- 主题（夜幕/羊皮卷）、BGM（bgm-main.mp3 单实例循环、开关+音量持久化、暂停保进度）、交互音效（WebAudio 合成）

## 4. 设计语言（不可漂移项）

- 碑文史诗风：金色 #C6A15B 强调、暗色卡片、圆角、衬线标题、箴言体文案
- 揭晓/成就/知识卡统一用金色碑文全屏层（ᛟ 印记 +「铭记于心」类按钮）
- 数值一律整数显示；概率与掉落用聚合 toast，不刷屏

## 5. 质量基线

- 每次迭代：平台 lint 全绿 + 线上无头浏览器行为验证（不止看 publish 状态——发布有传播延迟，已三次踩坑）
- 本地版：vitest 全量通过 + 构建通过
- 测试资产：/tmp/web-audit/ 系列脚本（路由走查/登录/眷顾/碎片/签到/翻牌）

## 6. 路线图与优先级

- **P0（下一步）**：本地版回灌——碎片经济/签到/翻牌同步到 uni-app 版，结束双版本功能不对齐状态
- **P1**：九界拼图小游戏（掉法器碎片）；神谕历程回顾（已解锁神谕可回看）
- **P2**：条目出处小字（sources）；内容补厚（诺伦/女武神/巨人族谱）；档案海报分享
- **明确不做**：账号云同步、社交、课程式学习、广告位
