# 精灵（Elf）"微光结契"交互系统

> 版本：1.0（2026-09-12）
> 姊妹篇：《耶梦加得交互系统文档》（高危观测体系）

## 一、定位概述

精灵（光明精灵）是北欧神话中亚尔夫海姆的灵性种族，本项目中的**善良生物互动代表**。与耶梦加得的"高危观测"体系形成镜像差异化：精灵不支持观测克制玩法，而是提供**双向羁绊养成**。

**核心定位**：可以被靠近、回应、赠礼与缔结友谊的存在。惊扰只会让它们回避，永远不会带来死亡或冻结结局。

**徽章原则**：羁绊产出徽章——徽章是"关系"的证明，只有善良生物产出；耶梦加得等灾厄生物的交互零徽章（观测者的代价本身就是结局）。

## 二、与耶梦加得体系的差异化对照

| 维度 | 耶梦加得（高危观测） | 精灵（微光结契） |
| --- | --- | --- |
| 叙事基调 | 敬畏、恐惧、终末感 | 温柔、耐心、自然灵性 |
| 交互方向 | 单向：你观测它，它从不回应 | 双向：它观察你、回应你、回赠你 |
| 核心资源 | 克制（少做为好） | 耐心（慢做为好，急了会惊扰） |
| 危险来源 | 玩家心智负荷 + 居民敌视 | 林间静谧被打破（对象状态） |
| 失败代价 | 不可逆：失踪、档案冻结 | 可逆：回避 → 静候 3 次即回归 |
| 终局 | 见证与记录 | 缔结"亚尔夫之友"（可继续互动） |
| 独有机制 | 触碰确认弹窗、一次性死亡警告 | 节奏机制（连续静候门槛）+ 回赠事件 |
| 徽章 | 无 | 6 枚，随互动事件逐个显现 |

## 三、状态系统

### 3.1 状态字段（存储 key：`elf_spirit_state`）

| 字段名 | 默认值 | 说明 |
| --- | --- | --- |
| trust | 0 | 信任之光 0–100（同步为 bondExp，驱动羁绊条） |
| disturbance | 0 | 惊扰度 0–100（静谧条反向显示：100 − disturbance） |
| quietStreak | 0 | 连续静候计数（共鸣动作的解锁门槛） |
| receding | false | 精灵回避中（可逆；期间仅"静候"可用） |
| recedingQuietCount | 0 | 回避期间的静候计数（满 3 次回归） |
| callCount | 0 | 呼唤累计次数（≥2 直接触发回避） |
| goodGifts | 0 | 林间安宁时的赠礼次数（回赠事件门槛） |
| returnedOnce | false | 曾经历"回避→回归"（守候者徽章） |
| unlockedEvents | [] | 已触发事件 |
| stats | {...} | 各动作计数（listen/gift/wait/resonate/guard/call） |
| badges | {...} | 徽章解锁快照（随状态持久化） |

### 3.2 静谧度等级（显示文案）

| 惊扰度 | 显示 |
| --- | --- |
| 0–29 | 安宁 |
| 30–59 | 略有动静 |
| 60–79 | 草木不安（进度条转警示红边） |
| 80–100 | 噪声四起（触发回避） |

### 3.3 信任阶段（bondStage）

| trust | 阶段 | 情绪 |
| --- | --- | --- |
| 未收藏 | 未发现踪迹 | 疏离 |
| 1–19 | 初见微光 | 警觉 |
| 20–39 | 林间相遇 | 回应 |
| 40–69 | 赠礼往来 | 接纳 |
| 70–99 | 光之共鸣 | 亲近 |
| 100 | 亚尔夫之友 | 信任 |

## 四、互动按钮系统

| 按钮 | 解锁条件 | 信任 | 惊扰 | 边框 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 静候 | 初始 | +2 | **-8** | 绿（safe） | 唯一降惊扰手段；回避期间唯一可用动作 |
| 倾听 | 初始 | +3 | +1 | 灰（low） | |
| 赠礼 | 信任≥10 | +6 / +3* | +4 | 灰（low） | *惊扰度≥50 时视为"不合时宜的赠礼"，收益减半 |
| 呼唤 | 信任≥30 | -5 | +15 | 红（extreme） | 需确认弹窗；累计 2 次直接触发回避 |
| 共鸣 | 信任≥40 且连续静候≥2 | +8 | +6 | 金（gold） | 节奏机制：做其他动作会清零静候连击 |
| 守林 | 信任≥60 | +4 | 0 | 绿（safe） | 无惊扰的付出型动作 |

**呼唤确认弹窗**（镜像耶梦加得"触碰"确认）：

```
title: 确认
content: 你确定要出声呼唤吗？林间的宁静一旦打破，再想复原就需要更久的等待。
confirmText: 呼唤
cancelText: 沉默
```

选择沉默时记录消息："你选择了沉默。"

## 五、事件触发机制

### 5.1 事件一：铁器的噪声（负面 · 可逆）

**触发条件**（任一）：
- 惊扰度 ≥ 80
- 呼唤累计 ≥ 2 次（进入回避时计数清零：回归后需重新积累两次呼唤才会再次触发）

**后果**：
- `receding = true`，互动仅剩"静候"
- 信任 -10（不清零）
- 连续静候 3 次后回归：`receding = false`，记录 `returnedOnce = true`，解锁"静默守候者"徽章
- 事件写入 `unlockedEvents`（事件卡仅首次展示，回避可重复发生）

**与耶梦加得"档案冻结"的差异**：回避是可逆的关系退步，不是结局。

### 5.2 事件二：林间的回赠（正向 · 耶梦加得体系没有的"双向时刻"）

**触发条件**（同时满足）：
- 信任 ≥ 50
- 安宁赠礼（好礼）≥ 3 次

**后果**：
- 全屏庆祝："✦ 林间的回赠 —— 它第一次主动走向你"
- 解锁"微光赠予者"徽章

### 5.3 一次性温和提示（镜像"你应该离开。"）

**触发条件**：惊扰度 ≥ 60 且未触发过

**提示消息**："它停下了动作，正在看着你。"（仅进入消息日志，不做全屏层——善良生物的警告是提醒，不是恐吓）

## 六、徽章系统（仅善良生物产出）

| 徽章 | id | 解锁条件 |
| --- | --- | --- |
| 林间倾听者 | elf-listener | 倾听累计 ≥ 5 次 |
| 静默守候者 | elf-watcher | 首次经历"回避→静候回归" |
| 微光赠予者 | elf-giver | 触发"林间的回赠"（安宁赠礼 ≥3） |
| 光之共鸣者 | elf-resonance | 共鸣累计 ≥ 3 次 |
| 亚尔夫守林人 | elf-warden | 守林累计 ≥ 5 次 |
| 亚尔夫之友 | elf-friend | 信任达 100（终局） |

**显示规则**：徽章随事件逐个显现；一枚未解锁时仅显示"未知徽章"占位（保持仪式感）。灾厄生物（abyss/danger/极高危险度）整个徽章模块隐藏。

## 八、本地存储

- **Key**：`elf_spirit_state`（配置于种子 `spiritConfig.storageKey`）
- **读取**：onLoad 且 spirit 类型时
- **保存**：每次动作 / 徽章解锁后
- **结构**：`{ ...elfState, badges: { badgeId: unlocked } }`
- **回归修复**：旧版精灵羁绊刷新即丢；现在 trust/徽章/事件全部持久化，刷新后 `bondExp = max(seed, trust)` 恢复显示

## 九、重置机制

点击"已收藏 · 移除记录"时弹窗确认（镜像耶梦加得）：

```
title: 告别这片林地
content: 将清空信任之光、惊扰记录、事件叙事与全部徽章，从初见微光重新开始。确定吗？
confirmText: 告别
cancelText: 留下
```

确认后清空 storage、内存状态与全部徽章。

## 十、数据配置

全部配置位于 [norseCreatures.js](../src/data/norseCreatures.js) 精灵条目的 `spiritConfig` 字段（文献数据库 `creatures` 集合，支持运行时热更新调平衡）：

```
spiritConfig: {
  storageKey, stages[], stageInitial, stageFinalTitle,
  actions[] (key/label/unlock/trust/disturb/tone/message/messageDisturbed/confirm/requireQuietStreak),
  events { gaze, ironNoise, returnGift },
  receding { enterMessage, quietNeed, returnMessage, trustPenalty },
  badgeRules { listen, resonate, guard, goodGift, friendTrust }
}
```

无 `spiritConfig` 的 spirit 类型生物自动回落到旧的纯羁绊逻辑（向后兼容）。

## 十一、验收标准

| 序号 | 验收项 | 预期结果 |
| --- | --- | --- |
| 1 | 未解锁状态 | 显示探索任务卡，"静候一次"解锁收录 |
| 2 | 初始动作 | 仅 静候/倾听 可用，赠礼需信任≥10 |
| 3 | 双计量条 | 信任（金）递增、静谧（绿）随动作降低 |
| 4 | 惊扰提示 | 静谧≤40 时一次性出现"它停下了动作，正在看着你。" |
| 5 | 回避触发 | 惊扰≥80 或呼唤 2 次 → 仅剩"静候"按钮 + 回避卡 |
| 6 | 回避恢复 | 连续静候 3 次 → 回归 + 解锁"静默守候者" |
| 7 | 回赠事件 | 信任≥50 且安宁赠礼≥3 → 庆祝 + "微光赠予者" |
| 8 | 共鸣门槛 | 做任意非静候动作后，共鸣立即锁定（需重新连续静候 2 次） |
| 9 | 徽章逐个显现 | 徽章区随事件逐步亮起；灾厄生物无徽章模块 |
| 10 | 终局 | 信任 100 → "亚尔夫之友"金卡 + elf-friend 徽章，互动不冻结 |
| 11 | 持久化 | 刷新后信任/惊扰/事件/徽章全部保留 |
| 12 | 重置 | "告别这片林地"确认后全部清空 |
| 13 | 隔离性 | 耶梦加得及其他生物逻辑不受影响 |
